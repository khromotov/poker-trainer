# Poker Trainer

Локальный тренажёр префлоп equity двух конкретных рук Texas Hold’em. Результат — оценка Монте-Карло; equity учитывает половину ничьих. Random выбирает реальные комбинации из колоды, поэтому 169 типов стартовых рук встречаются с естественными, а не одинаковыми частотами. Balanced выбирает раздачи с одной или несколькими вычисляемыми метками; «близкие» означает близость суммы рангов, доминирование определяется общей старшей картой и разными кикерами. Это упрощённые категории, не оценка стратегии.

## Запуск

Нужен Node.js 22 и npm. Выполните `npm install`, затем `npm run dev`. Проверки: `npm test`, `npm run typecheck`, `npm run build`. Тяжёлый расчёт выполняется в Web Worker; история хранится в IndexedDB, настройки — в localStorage.

## GitHub Pages

Создайте репозиторий `poker-trainer`, отправьте файлы в ветку `main` и выберите Settings → Pages → Source → GitHub Actions. Workflow запускает проверки и публикует сборку. Для другого имени репозитория измените `base` в `vite.config.ts`. Первый запуск и обновление требуют подключения.

## iPhone и офлайн

Откройте сайт в Safari, нажмите «Поделиться» → «На экран Домой». После полной первоначальной загрузки закройте приложение, включите авиарежим и проверьте запуск, расчёт и статистику. Закройте и откройте приложение снова, проверьте историю. После публикации обновления проверьте уведомление и обновление по нажатию. Это ручные проверки: сборка сама по себе не подтверждает работу на устройстве. Очистка данных Safari, удаление приложения или освобождение места системой могут удалить локальную историю — сохраняйте экспорт JSON.

## Границы

Monte Carlo не гарантирует фиксированную максимальную ошибку. Тренажёр двух рук и новый режим стола используют независимые базы истории.

## Префлоп · стол

Настройте своё место и дилера, имена и стеки игроков (до 10). Значения по умолчанию: 30 000, SB 100, BB 200, анте большого блайнда 200. Включённое реэнтри автоматически возвращает выбывшему стартовый стек после распределения банка. Выключите реэнтри в настройках, когда оно закрывается. Изменённые блайнды применяются со следующей раздачи; настройки реэнтри — при завершении текущей.

Начните раздачу, вводите действия по очереди. Поле «Ставка до» означает полную ставку на текущей улице **без анте**; доплата вычитается автоматически. Например, после SB 100 ставка до 600 стоит ещё 500. Отмена хода доступна в открытой вкладке; сама раздача восстанавливается после перезагрузки. История ходов не содержит ваших карт.

В ваш ход показывается 13×13 матрица всех рук. По нажатию можно посмотреть модельные оценки действий в BB. Штриховка означает, что выбор действия статистически неустойчив. Изменение ситуации отменяет прежний Worker; результат другого хода не применяется. Настройка точности: 160 / 400 / 1 000 выборок на руку.

После префлопа укажите итоговые вклады игроков за всю раздачу (с блайндами и анте), если игра продолжалась, и выберите победителей каждого банка. Несколько отмеченных победителей делят банк. Неуравнённая часть ставки возвращается, нечётные фишки распределяются по часовой стрелке после дилера. Затем автоматически обновляются стеки и позиция дилера. Изменение состава и стеков во время раздачи требует явной её отмены. При коротком стеке BB принято правило **сначала анте, потом блайнд**.

В настройках доступны история, JSON экспорт и импорт с проверкой формата и защитой от дубликатов. Распределение и запись результата выполняются в одной транзакции. В таблице блайндов задайте строки `100/200`, `200/400` и т. д.; кнопка «Блайндс ап» выбирает следующий больший BB, затем сохраните настройки.

### Что означает приближённая модель

Это **не решённое GTO-равновесие** и не проверенная турнирная стратегия. Закрытые или непроверенные сторонние таблицы не используются. Диапазоны и вероятности колла усреднённого оппонента заданы нашими явными правилами по позиции, действиям и размеру ставок. Выборка учитывает конкретные комбинации, блокеры и изменения этих диапазонов.

Сравниваются модельные chipEV фолда, колла/чека, одного размера рейза и разрешённого моделью олл-ина. Оппоненты в продолжении модели только коллируют или фолдят, после чего доска доигрывается без последующих ставок. Глубокий опен-пуш исключён из набора кандидатов: олл-ин рассматривается при эффективном стеке до 25 BB, существенной уже имеющейся ставке или после нескольких повышений. Ручной ввод олл-ина остаётся доступен по правилам торгов.

Такая модель особенно ограничена на глубоких стеках: она не оценивает будущие ререйзы, позиционную реализацию equity и постфлоп-игру. Числа EV относятся **только к этому предположению**, а не к реальной ожидаемой прибыли. Статистическая неопределённость не включает ошибку самой модели. ICM, рейтинг, рейк и индивидуальная статистика оппонентов не учитываются. Скрытые карты сфолдивших игроков не восстанавливаются; выбор диапазонов после удаления блокеров последовательный и также приближённый.

### Проверка

`npm test`, `npm run typecheck`, `npm run build`. Автоматические тесты покрывают комбинации, матрицу, воспроизводимость расчётов, побочные банки, короткие олл-ины, повторное открытие торгов, разделённые банки, реэнтри, сохранность суммы фишек и импорт/экспорт. На iPhone дополнительно проверьте матрицу в свой ход, восстановление текущей раздачи, экспорт, офлайн после установки и обновление PWA. Десктопная проверка браузера не заменяет тест на физическом iPhone.

Расширение на следующие улицы потребует отдельного дерева игры, ввода общих карт и обработки конкретных мастей. Предметный движок, хранение, UI и модуль рекомендаций разделены, поэтому этот этап можно добавить отдельно.
