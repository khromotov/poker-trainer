# Poker Trainer

Два локальных тренажёра Texas Hold’em с интерфейсом для телефона: **«Префлоп дуэль»** и **«Тренажёр решений»**. [Открыть приложение](https://khromotov.github.io/poker-trainer/).

## Префлоп дуэль

Оцените equity двух конкретных рук, проверьте ответ расчётом Монте-Карло и переходите к следующей задаче. Equity — вероятность победы плюс половина вероятности ничьей. Проценты можно вводить с точкой или запятой: `40.5` и `40,5` равнозначны.

Режим Random выбирает реальные комбинации из колоды; типы стартовых рук встречаются с естественными частотами. Balanced и Mixed используют упрощённые категории для разнообразия задач. В настройках доступны режим и число симуляций, в статистике — история, ошибки и JSON экспорт/импорт. Монте-Карло не гарантирует фиксированную максимальную погрешность.

## Тренажёр решений

Нажмите «Получить раздачу»: приложение раздаст вам и ботам настоящие случайные карты из одной колоды. Боты сами играют до вашего хода. Выберите фолд, чек, колл, рейз или олл-ин; поле рейза означает **полную ставку на текущей улице**, без анте. Доплата и банки учитываются автоматически.

После вашего действия появляется учебная оценка с объяснением. Пока вы не нажали «Продолжить раздачу», показывается ситуация **до решения**: следующие карты и действия не раскрываются. Раздача продолжается через флоп, тёрн и ривер, либо заканчивается раньше после фолдов. На вскрытии автоматически учитываются лучшие пять карт, побочные банки и делёж. Затем доступны карты соперников, причины ходов ботов и разбор ваших решений. Выигрыш сам по себе не означает правильное решение, проигрыш — ошибку.

Настройки: от 2 до 10 игроков, по умолчанию 10; стартовый стек 30 000, блайнды 100/200 и BB ante 200. Можно изменить число игроков и стартовый стек, включить или выключить случайную глубину стеков. Новые настройки применяются со следующей раздачи. Каждая раздача самостоятельная: это не непрерывный турнир со сменой уровней и реэнтри.

### Как устроена оценка

Это **авторская учебная модель, не GTO-солвер и не точный расчёт EV**. Стратегии и предполагаемые диапазоны заданы эвристическими правилами с учётом позиции, действий, ставок, структуры борда и стиля соперника. Оценка equity использует случайные гипотетические комбинации из этих диапазонов; будущие ставки не решаются полным деревом. ICM, рейтинговые очки и рейк не учитываются. Погрешность выборки не измеряет ошибку стратегической модели.

Каждый бот принимает решение по своим картам и публичной информации. Модуль оценки вашего действия получает отдельное публичное наблюдение: вашу руку, открытые карты, стеки и историю ставок. Реальные карты соперников, будущий борд и приватные объяснения ботов в него не передаются. Нет правила «готовый натс всегда чек/колл»; допустимость агрессии зависит от ситуации и явно заданной модели.

Режим ручного ведения стола с матрицей рекомендаций снят с главного меню. Его прежние локальные сохранения остаются нетронутыми.

## Данные и офлайн

Тренажёры работают локально, без API. История дуэлей хранится в IndexedDB `poker-trainer`, решения — в отдельной базе `poker-decisions`. Прежняя база стола `poker-table` не удаляется и не заменяется. Общая цветовая тема хранится в localStorage.

Текущая раздача сохраняется после каждого действия вместе с полной колодой, картами и паузой оценки, чтобы после перезагрузки продолжить тот же сценарий. Запись завершения и архива атомарная. Экспорт решений содержит **только завершённые раздачи**: их карты, действия и оценки. Импорт проверяет формат, добавляет отсутствующие архивы и не заменяет текущую тренировку. Данные сохраняются на конкретном устройстве; для переноса используйте JSON экспорт.

Первый запуск и загрузка обновления PWA требуют сети. После полной загрузки приложение и расчёты доступны офлайн. На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой». Проверка на физическом iPhone остаётся ручной: запуск в авиарежиме, расчёт в обоих тренажёрах, восстановление после закрытия, экспорт истории и обновление по уведомлению. Десктопная сборка не подтверждает эти проверки. Очистка данных браузера может удалить локальные сохранения.

## Разработка и публикация

Нужен Node.js 22 и npm:

```sh
npm ci
npm run dev
```

Проверки перед публикацией:

```sh
npm test
npm run typecheck
npm run build
```

Расчёты ботов и учебных оценок выполняются в Web Worker. Автоматические тесты проверяют комбинации, легальность ставок, сохранность фишек, побочные банки, переходы улиц, скрытие приватных данных, воспроизводимость раздач, границы учебной модели и независимое хранение истории.

GitHub Pages публикуется workflow [pages.yml](./.github/workflows/pages.yml) после push в `main`: тесты → проверка типов → сборка → публикация. В настройках репозитория выберите Pages → Source → GitHub Actions. При другом имени репозитория измените `base` в [vite.config.ts](./vite.config.ts). После успешной публикации примите предложенное приложением обновление.
